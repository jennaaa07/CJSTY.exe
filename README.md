# 🌱 BloomPath

### Grow your skills. Navigate the future of work.

BloomPath is an AI-readiness and career-planning web application designed to help students, fresh graduates, working adults, and career changers explore future career opportunities, identify skill gaps, and plan their learning journey.

By combining labour-market insights with skills-based career matching, BloomPath aims to help users make more informed decisions in a rapidly changing world of work.

## 🎯 Problem Statement

The rapid advancement of artificial intelligence is changing job roles and the skills employers need. Many people may struggle to understand which skills to develop, which career paths to consider, and how to prepare for future opportunities.

BloomPath aims to make career planning more accessible by connecting users' existing skills with potential career paths and practical learning recommendations.

## 💡 Our Solution

BloomPath provides a guided career-planning experience that helps users:

- Build a profile of their existing skills.
- Explore labour-market and future-skills trends.
- Discover potential career matches and understand their skill gaps.
- Explore a personalized learning roadmap.
- See how selected careers or skills relate to the United Nations Sustainable Development Goals (SDGs).
- Compare moderate and rapid AI-adoption scenarios to explore how career priorities may change.

## ✨ Key Features

### 1. Skills Profile
Users can enter their skills to establish a starting point for career exploration.

### 2. Labour-Market Insights
Explore labour-market indicators with source links and observation dates. These indicators provide context for understanding the changing world of work.

### 3. Career Matching and Skills Gap Analysis
Explore potential career matches and identify skills that may need further development.

### 4. Learning Roadmap
View suggested learning steps and resources to help plan skill development.

### 5. SDG Mapping
Connect selected careers and skills to relevant United Nations Sustainable Development Goals.

### 6. Career Resilience Simulator
Compare moderate and rapid AI-adoption scenarios to explore how career recommendations or skill priorities may differ.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/jennaaa07/CJSTY.exe.git
   ```

2. Navigate to the project folder:

   ```bash
   cd bloompath
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

> If PowerShell blocks `npm`, try `npm.cmd install` and `npm.cmd run dev`.

## 📊 Data and Sources

BloomPath uses labour-market information to provide context for career exploration.

- **Department of Statistics Malaysia (DOSM) / OpenDOSM:** [Labour Force Survey Monthly](https://open.dosm.gov.my/data-catalogue/lfs_month)
- **API documentation/data endpoint:** [Malaysia Open Data API](https://api.data.gov.my/data-catalogue?id=lfs_month&sort=-date&limit=6&include=date,u_rate,p_rate,ep_ratio,lf_employed,lf_unemployed)

Always check the source and observation date when interpreting labour-market indicators. National labour statistics provide broad economic context and do not, by themselves, predict demand for a specific occupation or AI's impact on that occupation.

## 🌍 Sustainable Development Goals

BloomPath aims to support informed career development and lifelong learning, with relevant career or skill mappings to the United Nations Sustainable Development Goals.

- **SDG 4 — Quality Education:** Supporting learning and skills development.
- **SDG 8 — Decent Work and Economic Growth:** Supporting career exploration and workforce readiness.

## ⚠️ Limitations

- Career matches and scenario comparisons are exploratory guidance, not guarantees of future employment.
- Labour-market indicators may describe the wider workforce rather than demand for a specific job.
- Learning resources and recommendations should be checked for availability, cost, and relevance.
- BloomPath is intended to support human decision-making, not replace professional career advice.

## 🔮 Future Improvements

- Expand verified occupation-level and skills-demand data sources.
- Improve explanations and evidence behind career matches.
- Add more verified free or low-cost learning resources.
- Enhance scenario modelling and uncertainty communication.
- Improve accessibility and user experience.
